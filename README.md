# CLI plugins for Claude

Two plugins for [CLI](https://clicloud.app), the agent-native cloud. Pick one.

| Plugin | Runs | Payments | Install |
| --- | --- | --- | --- |
| `clicloud` | Nothing locally: connects to CLI's hosted MCP server and signs in with OAuth | None in Claude: add credit in the dashboard | `/plugin install clicloud@clicloud` |
| `clicloud-x402` | `npx @clicloud-app/mcp` on your machine | x402 USDC from an agent wallet, up to your limit | `/plugin install clicloud-x402@clicloud` |

Add the marketplace first: `/plugin marketplace add clicloud-app/claude-plugins`.

The `clicloud` plugin is the one listed in Claude's directory. Directory connectors can't move money,
so it has no payment tools; agents still spend the project's credit on hosting within the caps you set.
Use `clicloud-x402` when you want an agent to pay for things itself from a wallet you fund.

## Publishing

This folder is generated by `npm run distribution` in the CLI repository. Publish it as the
`clicloud-app/claude-plugins` GitHub repository. Check each plugin with `claude plugin validate plugins/<name>`
first, and raise the version in packages/cli/package.json for every release.
